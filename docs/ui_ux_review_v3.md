## 2. 交互与视觉建议（10 条）

1. **一个主行动：录音。** 底栏只留一颗录音键。记录空态不要再放「开始录音」实心按钮，改成一句指向底栏的说明。
2. **三个 Tab 职责互斥。** 记录 = 片段流；今日 = 按日复盘（可下钻到片段）；待办 = 未完成 inbox。设置只从右上角齿轮进。
3. **底栏改成「2 + 录音 + 1」。** 左：记录、今日；中：上浮麦克风；右：待办。录音键必须落在预留空洞里，不能和 Tab 重叠。
4. **产品词统一，协议词藏起来。** 对外只用：随身 / 会议 / 复盘。代码里尽快把 tag `"LifeLog"` 改成 `"随身"`，`recordingMode` 可暂时保留 `lifelog` 以免动后端，但 UI 和筛选禁止再用这个词。
5. **待办只在「待办」勾选。** 纪要页、今日页只展示，点击跳到待办或源片段；或：三处都可以勾，但必须是同一条记录上的同一条 JSON，今日不再复制一份「统一待办」造成重复行。
6. **今日要能看见当天片段。** 复盘上方加「当天 N 段」列表（只读摘要），点进去进纪要。没有片段时 CTA 指向录音，而不是生成。
7. **设置改成单页分组，去掉内嵌 4 Tab。** 顺序：权限（可点去授权）→ 录音默认 → 盲操 → 引擎 → 诊断。失败重试放到记录页的失败状态，不要藏在关于里。
8. **角色色只用一套。** 随身 = `AppColor.primary`（薄荷），会议 = `secondary`（蓝），复盘 = `tertiary`（紫）。禁止再拿 `MintCyan` vs `NeonGreen` 当对比色。
9. **安全区一次算清。** Tab 页只吃 Scaffold `paddingValues` + 水平 `pagePaddingH`；列表底部留 8–16dp 即可，删掉额外 80dp。Overlay（录音/纪要/设置）自己垫 status + nav + ime。
10. **返回语义明确。** 录音中返回 = 最小化到通知（不 finish）；纪要/设置返回 = 关 overlay；根 Tab 返回 = 再按一次退出。

## 3. 建议的 3.0 信息架构

```
说了啥
├── 记录          片段时间线（随身 / 会议 / 处理中 / 失败）
│     └── 纪要     一篇录音的标题、摘要、待办、文稿、回放、AI 重提炼
├── 今日          按日复盘（今天 / 昨天 / 前天）
│     ├── 当天片段  可点进纪要
│     └── 复盘正文  综述 / 社交 / 工作 / 关键时刻 / 当日待办（跳转）
├── 待办          全局未完成 inbox（来源：片段 + 复盘）
│     └── 点来源    片段→纪要；复盘→今日对应日期
├── 设置（二级）   权限 / 录音 / 盲操 / 引擎 / 诊断
└── 系统入口（不占 Tab）
      ├── 底栏录音键（可按设置：直接开 或 先选随身/会议）
      ├── 桌面快捷方式 / 快捷设置磁贴（走默认模式）
      └── 音量 +/- 双阶盲操（按时长分模式，文案必须写「同时按两键」）
```

**主屏默认落在「记录」。** 录音不是 Tab，是全局能力。

**数据层建议（仍不改后端协议）：**

| 对象 | 存储 | 识别 |
|---|---|---|
| 随身片段 | `audio_records` + 真实文件 | `recordingMode != "meeting"` 且不是复盘 |
| 会议片段 | 同上 | `recordingMode == "meeting"` |
| 每日复盘 | 合成行，`sessionId = digest_yyyy-MM-dd`（新行）；旧 `lifelog_` 继续识别 | `isDailyDigest()` |
| 待办 | 仍挂在记录的 `actionItems` JSON，不新建表 | `TasksScreen` flatten |

P0-1 的修法：今日收集当天片段时，**只排除复盘行**（`isDailyLifeLogSummary()`），不要用 `tags.contains("LifeLog")`。新写入的随身 tag 改为 `"随身"`。

## 4. 关键页布局方向

### 底栏

```
[ 记录 ]  [ 今日 ]     ( 🎤 )     [ 待办 ]
                 上浮 56dp
```

- 中间空洞宽度 = 录音键 + 16dp，且必须是 Row 的几何中心
- 选中色 = 品牌薄荷；未选中 = muted
- 录音中：整条底栏换成录音页，不叠在 Tab 上

### 记录

```
记录                         ⚙  导入
[全部] [随身] [会议] [处理中] [失败]
卡片：时间 · 模式徽标 · 时长 · 状态
      标题
      两行摘要
      如有待办：N 项未完成
```

空态：插画/符号 +「还没有记录」+「点底部麦克风开始，或右上角导入」。不要第二颗大按钮。

### 今日

```
今日  ·  全天复盘              ⚙  复制
[今天] [昨天] [前天]                 2026-09-11

当天 3 段 · 共 1 小时 12 分          [生成复盘]
  09:12  随身  散步碎碎念     →
  14:03  会议  周会           →

—— 复盘已生成则展开 ——
标题 / 金句 / 综述 / 社交 / 工作 / 关键时刻
当日待办 → 跳到待办 Tab 并高亮
```

### 待办

```
待办  ·  5 项进行中            ⚙  复制
[进行中 5] [已完成] [全部]

☐  把纪要发给小组
    会议 · 周会            09-11
```

整行点来源进纪要；圆圈只负责勾选。复盘来源进「今日」，不要进播放器。

### 纪要（overlay）

上：返回 + 标题「纪要」+ 复制。  
中：元信息、标题、摘要、待办（只读或勾选二选一，见你确认）、文稿/对白。  
下：有文件才钉播放条。  
「AI 工具 / 技术信息」默认折叠。复盘对象不要出现播放条，也不要用会议追问模板覆盖复盘结构。

### 录音中（overlay）

居中：角色色呼吸点、大号计时、随身/会议徽章、格式说明。  
底：危险色「完成并停止」。  
返回：回桌面，通知里继续；不要 finish Activity。

### 设置（overlay，单页滚动）

1. 权限（麦克风 / 通知 / 无障碍 / 电池，每行可点）  
2. 录音：启动策略（固定默认 / 每次选择）+ 默认模式 + 码率/格式 + 保留原件 + 通话续录  
3. 盲操：开关说明 + 两档时长 + 去开无障碍  
4. 引擎：供应商、Key、模型、连接测试；Prompt 默认折叠  
5. 诊断：复制/分享日志；「重试失败录音」同时在记录-失败筛选里出现

1. **底栏结构**  
   - 推荐：记录 | 今日 | 🎤 | 待办（当前 3 Tab 语义，只修几何）  
   - 备选：记录 | 🎤 | 今日 | 待办（录音更居中，今日改到右侧）
