# 说了啥 4.0

一款个人语音记忆工具：保留说过的话，搜索原稿，核对来源，回听原音。Android 10+，跟随系统浅深色主题。

主页提供三个平级入口：**记忆 / 今日 / 待办**。设置位于右上角，录音按钮位于右下角。

- 随身：每五分钟或跨日封存片段，封存后逐步转写；停止后按话题统一整理。
- 会议：停止后再转写，整次会话保留为会议记录。
- 搜索原话：直接查询本机全文索引与中文子串。
- 问问记忆：从检索到的原稿窗口回答，引用必须能逐字对应原稿；没有来源时明确显示无依据。
- 待办：AI 只提炼候选。用户确认、忽略或完成的状态独立存储，重新整理不会重置已确认事项。
- 导入：保留一份音频原件，以流式解码形成临时 WAV 分片；整理成功后清理临时分片。
- 原音一直保留，手动清理才删除。删除整次记录时，已确认的待办保留并标记来源已删除。

录音可以收起、暂停、继续；返回页面不停止录音。回听会先暂停正在进行的录音，需要用户手动继续。没有真实逐字时间戳时，从相关音频片段起点回听。

升级与服务配置：

Room 结构升级至 6，提供从 3、4、5 的显式迁移，不使用破坏性回退。升级前复制旧数据库及 WAL，保留旧音频路径与待办状态。旧版文本可能经过模型改写，因此标记为“历史整理稿”，不会冒充原始 ASR，也不会自动重转整套历史录音。

首次使用需要在“设置 → 转写与整理”中填写服务配置。未配置服务时仍可本地录音。服务密钥按地址隔离，用 Android Keystore 加密保存，并排除于自动备份。云端使用 HTTPS，本地 HTTP 只接受回环、私有 IP 或 `.local` 地址。原稿与音频会按功能需要发送到用户配置的服务。

Android 构建与检查（JDK 17）：

```powershell
$env:JAVA_HOME = 'C:\Program Files\Microsoft\jdk-17.0.20.101-hotspot'
$env:PATH = "$env:JAVA_HOME\bin;$env:PATH"
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

在本机归档安装包：`apks/说了啥-v4.0.apk`。后端可选，详见 [网关说明](server/README.md)。
