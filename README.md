# 说了啥 5.0

一款个人语音记忆工具：保留说过的话，搜索原稿，核对来源，回听原音。Android 10+，跟随系统浅深色主题。

主页提供三个平级入口：**记忆 / 今日 / 待办**，放在底部悬浮栏里，录音键紧挨着它；录音时录音键变成带计时的红色胶囊，可直接暂停。设置和导入在右上角。

- 随身：每五分钟或跨日封存片段，封存后逐步转写；停止后按话题统一整理。
- 会议：停止后再转写，整次会话保留为会议记录。
- 搜索原话：直接查询本机全文索引与中文子串。
- 问问记忆：从检索到的原稿窗口回答，引用必须能逐字对应原稿；没有来源时明确显示无依据。
- 待办：AI 只提炼候选。用户确认、忽略或完成的状态独立存储，重新整理不会重置已确认事项。
- 导入：保留一份音频原件，以流式解码形成临时 WAV 分片；整理成功后清理临时分片。
- 原音一直保留，手动清理才删除。删除整次记录时，已确认的待办保留并标记来源已删除。
- 说话人与逐句时间（4.2）：使用阿里云百炼 `qwen-audio-3.1-asr-flash` 时，原话按句标出“说话人 N”和时间，点一句从该句回听；会议结束后整场一起转写，说话人编号前后一致；随身片段的编号只在本片段内有效。说话人只按声音区分，不识别身份，名字由用户在原话里设置并保存在本机。其他服务不返回这些信息，仍从片段开头回听。
- 热词（4.2）：在服务配置里填写人名、项目名和术语，百炼转写时作为热词使用。
- 导出原话（4.2）：记录详情右上角菜单，导出带时间、说话人和标记的纯文本。
- 原话连续阅读（4.2 界面）：一次记录的所有片段连成一篇，按说话人分段并配固定颜色和头像，可按说话人筛选；播放时高亮当前句并跟随滚动，一个片段播完自动接下一段，支持 1× / 1.5× / 2×。
- 标记重点（4.2 界面）：录音页和录音通知都有「标记」，原话里在对应位置显示「你标记的重点」，点一下从标记前 5 秒回听。录音页同时显示最近一段转写。
- 要点页（4.2 界面）：显示发言占比；候选待办直接在这里确认或忽略，已确认的可勾选完成；每条来源标出说话人、片段和时间。首页卡片显示转写进度。
- 界面重做（5.0）：「纸与墨」配色，暖纸底色、墨色文字、玉绿强调，录音是唯一的红色；卡片、胶囊、图标块和分段控件统一。录音页固定为深色舞台，圆形光晕随声音起伏，标记、停止、暂停排成一行。页面切换（含侧滑返回）统一为渐变，不再缩小消失。
- 不再默认选中任何转写服务（5.0）：新装后设置里没有预选项，首次使用先选服务商并填密钥，再确认数据外发，确认针对刚选的服务地址；没选服务就不会出现数据外发确认。阶跃星辰只是预设之一。已经填过阶跃密钥的老用户升级时会被保留为阶跃。
- 桌面小组件（5.0）：录音条（4×1，一键开始、暂停、标记、停止，计时由系统自己走）、快捷入口（2×2，随身 / 会议 / 搜索 / 待办）、待办清单（4×3，点一行勾掉一项）、今日回顾（4×2）。小组件开始录音走与快捷设置磁贴相同的同意和麦克风检查，不会绕过。
- 录音实时活动 / 流体云（5.0）：录音通知改到新的通知渠道并提高到默认重要度（仍然静音），设置 › 录音与快捷启动 新增「录音实时活动」，显示系统开关状态、跳转系统设置，也可以发一条 10 秒的示例通知来看效果。
- 转写与整理分开配置（4.3）：设置 › 转写与整理 分为「转写」和「整理与提问」。整理可以和转写用同一服务，也可以另选一家（DeepSeek、火山方舟·豆包、智谱 GLM、Google Gemini、百炼、阶跃、硅基流动，或任意 OpenAI 兼容地址），密钥按服务商分别保存。数据外发确认同时列出两个地址，新增或更换整理地址需要重新确认；整理改回与转写同一服务时不再询问。整理时按服务关闭模型思考（百炼 `enable_thinking`，DeepSeek / 豆包 / GLM `thinking`）；Gemini 不能关闭思考，按最低档 `low` 运行，不发送 temperature 和 JSON 模式。

录音可以收起、暂停、继续；返回页面不停止录音。回听会先暂停正在进行的录音，需要用户手动继续。服务没有返回逐句时间时，从相关音频片段起点回听。

升级与服务配置：

Room 结构升级至 8（7：原稿表的逐句时间与说话人列；8：每次记录的说话人名字，以及录音时的标记表 `capture_marks`），提供从 3、4、5、6、7 的显式迁移，不使用破坏性回退。每次结构升级前把旧数据库及 WAL 复制到应用内部 `files/backups/pre-v<目标结构>/`（现为 `pre-v8/`），保留旧音频路径与待办状态。旧版文本可能经过模型改写，因此标记为“历史整理稿”，不会冒充原始 ASR，也不会自动重转整套历史录音。

首次使用需要选择服务商并填写密钥（引导页或“设置 → 转写与整理”），没有默认服务。转写预设有阿里云百炼（北京，境内）、阿里云百炼（新加坡，境外）、硅基流动、阶跃星辰和本地/自定义；整理另可选 DeepSeek、火山方舟·豆包、智谱 GLM、Google Gemini 和自定义 OpenAI 兼容服务。百炼一个密钥同时用于转写和整理，默认整理模型为 `qwen3.8-flash`，北京与新加坡的密钥不通用。整理使用电脑上的 OpenAI 兼容服务（本机网关、反代等）时选「自定义整理服务」：HTTP 只允许 localhost，需先 `adb reverse tcp:<端口> tcp:<端口>`；也可以用带正式证书的 HTTPS 隧道（如 Tailscale serve），不插 USB 也能用。电脑不在线时整理任务会排队等待，转写不受影响。未配置服务时仍可本地录音。服务密钥按服务商分别保存，用 Android Keystore 加密，并排除于自动备份。联网处理前需要确认数据外发；更换服务地址后需重新确认，确认前录音只保存在本机。云端使用 HTTPS；HTTP 只允许 `localhost`、`127.0.0.1` 和模拟器的 `10.0.2.2`，局域网 IP 的 HTTP 地址会被拦截。手机连接电脑上的网关时，用 USB 执行 `adb reverse tcp:8000 tcp:8000`，再填写 `http://localhost:8000/v1`。原稿与音频会按功能需要发送到用户配置的服务。

Android 构建与检查（JDK 17）：

```powershell
$env:JAVA_HOME = 'C:\Program Files\Microsoft\jdk-17.0.20.101-hotspot'
$env:PATH = "$env:JAVA_HOME\bin;$env:PATH"
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

在本机归档安装包：`apks/说了啥-v{versionName}.apk`（当前 `5.0`）。后端可选，详见 [网关说明](server/README.md)。
